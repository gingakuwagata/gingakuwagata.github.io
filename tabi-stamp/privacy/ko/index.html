스탬프 여행 수첩 개인정보 처리방침

Yuto Kuwabara(이하 "제공자")는 스탬프 여행 수첩(이하 "본 앱")이 다루는 정보에 대해 다음과 같이 정합니다.

본 앱이 다루는 정보

  • 본 앱은 각 도도부현과 시구정촌에 설정한 단계, 스탬프의 날짜와 한마디, 스탬프 디자인, 사용자가 고른 사진을 다룹니다. 이 정보는 기기 안에 저장됩니다.
  • 1회 구매를 하고 기기에서 iCloud를 사용하는 경우, 사진을 제외한 기록(도도부현과 시구정촌의 단계, 스탬프의 날짜와 메모, 디자인)은 사용자 본인의 iCloud(Apple이 제공하는 CloudKit 비공개 데이터베이스)에 저장되며 같은 Apple 계정의 기기 간에 동기화됩니다. 사진은 iCloud로 보내지 않고 기기에만 저장합니다. 제공자는 이 내용을 볼 수 없습니다.
  • 사진은 사용자가 사진 보관함에서 고른 것만 읽습니다. 저장할 때 축소하여 다시 인코딩하므로 촬영 위치 등의 촬영 정보는 남지 않습니다. 공유용 이미지를 사진에 저장할 때는 사진 추가 권한을 요청합니다.
  • 본 앱은 계정 등록이 필요 없으며 광고, 이용 현황 분석, 오류 정보 수집 기능이 없습니다.
  • 필수 업데이트를 확인하기 위해 실행 시 GitHub Pages에 둔 설정 파일(update.json)을 읽습니다. 이때 일반적인 웹 요청 정보만 전송되며 기록 내용은 전송하지 않습니다.
  • 앱 내 구입과 결제는 Apple이 처리합니다. 제공자는 결제 정보를 받지 않습니다.

이용 목적과 외부 서비스

기록과 사진은 지도를 칠하고, 스탬프를 표시하고, 공유용 이미지와 CSV를 만드는 데에만 사용합니다. iCloud 동기화는 Apple Inc.가, 설정 파일 배포는 GitHub, Inc.가 각 서비스의 규정에 따라 처리합니다. 사용자가 공유나 CSV 내보내기를 하면 사용자가 고른 대상에 데이터가 전달됩니다. 법령에 따른 경우를 제외하고 사용자의 정보를 제3자에게 제공하지 않습니다.

저장과 삭제

기록과 사진은 앱 안에서 삭제하거나 앱을 삭제하면 기기에서 지워집니다. iCloud에 저장된 기록은 설정 > Apple ID > iCloud > 계정 저장 공간 관리에서 삭제할 수 있습니다. 제공자는 사용자의 기록을 보관하지 않습니다.
