スタンプ旅帳 プライバシーポリシー

Yuto Kuwabara（以下「提供者」）は、スタンプ旅帳（以下「本アプリ」）で扱う情報について、次のとおり定めます。

本アプリが扱う情報

  • 行った都道府県と市区町村の段階、スタンプの日付とひとこと、スタンプの柄、利用者が選んだ写真を扱います。これらは端末の中に保存します。
  • 端末で iCloud を使っている場合、これらの記録は利用者自身の iCloud（Apple の CloudKit の非公開のデータベース）に保存され、同じ Apple ID の端末の間で同期されます。提供者はこの内容を見ることができません。
  • 写真は、利用者が写真ライブラリから選んだものだけを読み込みます。保存のときに縮小して書き出し直すため、撮影場所などの撮影情報は残りません。シェア用の画像を写真に保存するときは、写真への追加の許可を求めます。
  • 本アプリはアカウントの登録を求めず、広告、利用状況の分析、障害の情報を集める仕組みを入れていません。
  • 強制アップデートの確認のため、起動したときに GitHub Pages に置いた設定ファイル（update.json）を読み込みます。このとき送られるのは通常のウェブの通信の情報だけで、記録の内容は送りません。
  • アプリ内課金の購入と支払いは Apple が処理します。提供者は支払いの情報を受け取りません。

利用目的と外部サービス

記録と写真は、地図を塗る、スタンプを表示する、シェア用の画像や CSV を作るためだけに使います。iCloud の同期は Apple Inc. が、設定ファイルの配信は GitHub, Inc. が、それぞれのサービスの規定に従って扱います。利用者がシェアや CSV の書き出しを行った場合は、利用者が選んだ共有先にデータが渡ります。法令に基づく場合を除き、利用者の情報を第三者に提供しません。

保存と削除

記録と写真は、アプリの中で消す、またはアプリを削除することで端末から消えます。iCloud に保存された記録は、iOS の設定の「Apple ID」→「iCloud」→「アカウントのストレージを管理」から削除できます。提供者は利用者の記録を保管していません。

地図データの出典

  • 「国土数値情報（行政区域データ）」（国土交通省）（https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2026.html）を加工して作成。2026年1月1日時点の行政区域。
  • 市区町村名のローマ字とハングルは、「全国地方公共団体コード」（総務省）（https://www.soumu.go.jp/denshijiti/code.html）の読みをもとに作成。
