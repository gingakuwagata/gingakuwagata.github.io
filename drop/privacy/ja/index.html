ドロップ プライバシーポリシー

Yuto Kuwabara（以下「提供者」）は、ドロップ（以下「本アプリ」）で扱う情報について、次のとおり定めます。

個人情報について

個人情報とは、個人に関する情報であり、当該情報に含まれる氏名、生年月日、電話番号、メールアドレスその他の記述等により特定の個人を識別することができるもの（他の情報と容易に照合することができ、それにより特定の個人を識別することができることとなるものを含みます）を指します。

本アプリが扱う情報

  • 入力したやることの名前、終えたやることの名前と色と終えた日時、終えた数は、端末の中にだけ保存します。提供者のサーバーにも、iCloud などの外部のサービスにも送りません。
  • アカウントの登録、サインイン、認証の仕組みはありません。氏名やメールアドレスを入力する必要はありません。
  • 利用状況の分析や広告のためのツール（計測の SDK）は入れていません。画面の閲覧や操作の履歴、端末の識別子を集めません。
  • 本アプリが通信するのは、次のものを読み込むときだけです。アップデートが必要かどうかを確かめるための設定ファイル（update.json）と提供者のほかのアプリの一覧（developer-apps.json）を GitHub Pages から、一覧に出すアプリのアイコン画像を Apple のサーバーから読み込みます。ほかのアプリを開いたときは、アプリの中に App Store の画面を読み込みます。どれも読み込むだけで、利用者の情報は送りません。読み込みのとき、通信の仕組みとして IP アドレスなどが GitHub と Apple に届きます。
  • 「このアプリをシェアする」を使った場合は、利用者が選んだ共有先に、本アプリを紹介する App Store のリンクが渡ります。やることの記録は渡りません。レビューの依頼には Apple の仕組みを使います。

利用目的と外部サービス

端末の中のデータは、やることの記録と表示のためだけに使います。上のファイルと画像の読み込みは、アップデートのお知らせと、ほかのアプリの紹介のためです。ファイルの配信は GitHub, Inc. が、アイコン画像と App Store の画面の配信は Apple Inc. が、それぞれのサービスの提供に必要な範囲で情報を取り扱います。法令に基づく場合を除き、利用者の情報を第三者に提供しません。

保存と削除

やることの記録は、アプリの中で消せます。終えた数を含む端末の中のすべてのデータは、アプリを削除すると消えます。提供者は利用者のデータを預かっていません。ご不明な点は、下記の連絡先までご連絡ください。

個人情報の管理およびセキュリティについて

提供者は、個人情報の正確性を保ち、これを安全に管理します。提供者は、個人情報の紛失、破壊、改ざんまたは漏えい等を防止するため、適正な情報セキュリティ対策を講じます。

プライバシーポリシーの改定

提供者は、個人情報の取り扱いに関する運用状況を適宜見直し、継続的な改善に努めるものとし、必要に応じて、本ポリシーを変更することがあります。変更後のプライバシーポリシーは、本サイト上で随時公表するものとします。
