Drop 隱私權政策

原文

Yuto Kuwabara（以下簡稱「提供者」）就Drop（以下簡稱「本應用程式」）所處理的資訊，規定如下。

關於個人資訊

個人資訊是指與特定個人相關的資訊，包括該資訊中含有的姓名、出生日期、電話號碼、電子郵件地址及其他描述等，可據此識別特定個人的資訊（包括可與其他資訊輕易對照、並據此識別特定個人的資訊）。

本應用程式處理的資訊

  • 您輸入的待辦事項名稱、已完成事項的名稱、顏色與完成時間以及已完成的數量，只儲存在您的裝置中，不會傳送到提供者的伺服器，也不會傳送到 iCloud 等外部服務。
  • 本應用程式沒有帳號註冊、登入或認證功能，無需輸入姓名或電子郵件地址。
  • 本應用程式未加入用於分析或廣告的工具（統計 SDK），不收集畫面瀏覽紀錄、操作紀錄或裝置識別碼。
  • 本應用程式只在讀取以下內容時連網：從 GitHub Pages 讀取用於確認是否需要更新的設定檔（update.json）與提供者其他應用程式的列表（developer-apps.json），從 Apple 的伺服器讀取列表中應用程式的圖示。開啟列表中的其他應用程式時，會在本應用程式內載入 App Store 頁面。本應用程式只讀取這些內容，不傳送您的資訊。讀取時，作為網路通訊的機制，IP 位址等資訊會到達 GitHub 與 Apple。
  • 當您使用「分享此應用程式」時，介紹本應用程式的 App Store 連結會傳給您選擇的分享對象，您的待辦紀錄不會被分享。請求評分使用 Apple 的系統功能。

使用目的與外部服務

裝置中的資料只用於記錄與顯示您的待辦事項。讀取上述檔案與圖片是為了通知更新與介紹其他應用程式。GitHub, Inc.（檔案發佈）與 Apple Inc.（應用程式圖示與 App Store 頁面）各自在提供其服務所需的範圍內處理資訊。除法律規定的情況外，提供者不會向第三方提供您的資訊。

儲存與刪除

您可以在應用程式內刪除待辦紀錄。刪除本應用程式時，裝置中包括已完成數量在內的所有資料都會清除。提供者不保管您的資料。如有疑問，請透過下方聯絡方式洽詢。

關於個人資訊的管理及安全

提供者將保持個人資訊的準確性，並妥善管理。提供者將採取適當的資訊安全措施，以防止個人資訊的遺失、毀損、篡改或洩露等。

隱私權政策的修訂

提供者將適時審查個人資訊處理的運營狀況，持續致力於改進，並在必要時修改本政策。修訂後的隱私權政策將在本網站上隨時公布。

關於個人資訊的披露等手續

本應用程式將對本人就其個人資訊提出的使用目的通知、披露、內容更正、添加或刪除、停止使用、刪除及停止向第三方提供（以下簡稱「披露等」）的申請，不遲延地予以回應。詳情請透過以下聯絡方式諮詢。
