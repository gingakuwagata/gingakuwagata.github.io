Drop 隐私政策

原文

Yuto Kuwabara（以下简称"提供者"）就Drop（以下简称"本应用"）所处理的信息，规定如下。

关于个人信息

个人信息是指与特定个人相关的信息，包括该信息中含有的姓名、出生日期、电话号码、电子邮件地址及其他描述等，可据此识别特定个人的信息（包括可与其他信息轻易对照、并据此识别特定个人的信息）。

本应用处理的信息

  • 您输入的待办事项名称、已完成事项的名称、颜色和完成时间以及已完成的数量，仅保存在您的设备中，不会发送到提供者的服务器，也不会发送到 iCloud 等外部服务。
  • 本应用没有账户注册、登录或认证功能，无需输入姓名或电子邮件地址。
  • 本应用未加入用于分析或广告的工具（统计 SDK），不收集画面浏览记录、操作记录或设备标识符。
  • 本应用仅在读取以下内容时联网：从 GitHub Pages 读取用于确认是否需要更新的设置文件（update.json）和提供者其他应用的列表（developer-apps.json），从 Apple 的服务器读取列表中应用的图标。打开列表中的其他应用时，会在本应用内载入 App Store 页面。本应用只读取这些内容，不发送您的信息。读取时，作为网络通信的机制，IP 地址等信息会到达 GitHub 和 Apple。
  • 当您使用"分享此应用"时，介绍本应用的 App Store 链接会传给您选择的分享对象，您的待办记录不会被分享。请求评分使用 Apple 的系统功能。

使用目的与外部服务

设备中的数据仅用于记录和显示您的待办事项。读取上述文件和图片是为了通知更新和介绍其他应用。GitHub, Inc.（文件分发）和 Apple Inc.（应用图标和 App Store 页面）各自在提供其服务所需的范围内处理信息。除法律规定的情况外，提供者不会向第三方提供您的信息。

保存与删除

您可以在应用内删除待办记录。删除本应用时，设备中包括已完成数量在内的所有数据都会消除。提供者不保管您的数据。如有疑问，请通过下方联系方式咨询。

关于个人信息的管理及安全

提供者将保持个人信息的准确性，并妥善管理。提供者将采取适当的信息安全措施，以防止个人信息的丢失、毁损、篡改或泄露等。

隐私政策的修订

提供者将适时审查个人信息处理的运营状况，持续致力于改进，并在必要时修改本政策。修订后的隐私政策将在本网站上随时公布。

关于个人信息的披露等手续

本应用将对本人就其个人信息提出的使用目的通知、披露、内容更正、添加或删除、停止使用、删除及停止向第三方提供（以下简称"披露等"）的申请，不迟延地予以回应。详情请通过以下联系方式咨询。
