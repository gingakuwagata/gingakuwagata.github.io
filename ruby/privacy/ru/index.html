Политика конфиденциальности Ruby Roll

Оригинал

Yuto Kuwabara (далее — «Поставщик») уделяет особое внимание защите персональных данных, доверенных приложению Ruby Roll (далее — «Приложение»).

О персональных данных

Персональные данные — это сведения о физическом лице, позволяющие идентифицировать конкретного человека по имени, дате рождения, номеру телефона, адресу электронной почты и иным сведениям, содержащимся в них (включая сведения, которые могут быть легко сопоставлены с иной информацией для идентификации конкретного лица).

Использование персональных данных

Поставщик использует персональные данные, получаемые через Приложение, в следующих целях:

  • Для аутентификации при использовании Приложения
  • Для обработки обращений пользователей
  • Для реагирования на нарушения условий и правил Приложения
  • Для отправки уведомлений и информации, связанной с Приложением

Сбор и использование данных об атрибутах и истории действий

Поставщик может использовать автоматически формируемые при использовании Приложения данные — такие как просмотренные экраны, страна или регион, user agent, версия ОС — в форме, не позволяющей идентифицировать конкретное лицо, в целях улучшения Сервиса.

Предоставление персональных данных третьим лицам

Поставщик не раскрывает и не предоставляет персональные данные (включая статистические данные, обработанные таким образом, что личность не может быть идентифицирована) третьим лицам без предварительного согласия соответствующего лица. Однако в следующих случаях Поставщик может раскрыть минимально необходимую информацию, определив получателя и содержание раскрытия:

Управление персональными данными и обеспечение безопасности

Поставщик поддерживает точность персональных данных и обеспечивает их безопасное управление. Поставщик принимает надлежащие меры информационной безопасности для предотвращения утраты, уничтожения, фальсификации или утечки персональных данных.

Изменения настоящей Политики конфиденциальности

Поставщик регулярно пересматривает практику обращения с персональными данными, стремится к их постоянному совершенствованию и может при необходимости изменять настоящую Политику. Изменённая Политика конфиденциальности будет публиковаться на данном сайте по мере необходимости.

Порядок раскрытия персональных данных

Приложение незамедлительно реагирует на запросы соответствующего лица об уведомлении о цели использования, раскрытии, исправлении, дополнении или удалении содержания, приостановке использования, удалении и приостановке предоставления третьим лицам его персональных данных (далее — «Запросы о раскрытии»).
