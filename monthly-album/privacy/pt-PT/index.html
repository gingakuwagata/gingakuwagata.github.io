Política de Privacidade do Álbum Mensal

Original

Yuto Kuwabara (doravante "Fornecedor") tem o máximo cuidado na gestão dos dados pessoais confiados ao Álbum Mensal (doravante "Aplicação").

Dados pessoais

Consideram-se dados pessoais as informações relativas a um indivíduo que permitam identificar uma pessoa concreta através de elementos como o nome, a data de nascimento, o número de telefone, o endereço de correio eletrónico ou outras indicações neles contidas (incluindo informações que possam ser facilmente cruzadas com outras informações de modo a identificar uma pessoa concreta).

Utilização dos dados pessoais

As fotografias, os vídeos, as notas e as seleções permanecem no dispositivo e não são enviados para o servidor do Prestador, salvo se optar por partilhá-los. O Firebase Authentication cria um identificador para início de sessão anónimo e verificação do acesso pago no Firestore. O Firebase Analytics recolhe dados de utilização sem o conteúdo das fotografias ou notas; o Crashlytics recolhe dados de falhas e do dispositivo. A Google trata os dados destes serviços e a Apple os dados de compras. Os dados são utilizados para fornecer e melhorar a Aplicação. Os dados locais podem ser apagados na Aplicação ou ao eliminá-la.

Gestão e segurança dos dados pessoais

O Fornecedor mantém a exatidão dos dados pessoais e gere-os de forma segura. O Fornecedor adota medidas adequadas de segurança da informação para evitar a perda, destruição, alteração ou divulgação indevida de dados pessoais.

Alterações à presente Política de Privacidade

O Fornecedor revê periodicamente a gestão dos dados pessoais, procurando uma melhoria contínua, e pode, sempre que necessário, alterar a presente Política. Qualquer versão revista da Política de Privacidade será publicada neste sítio sempre que necessário.

Procedimentos relativos à divulgação de dados pessoais

A Aplicação responderá sem demora aos pedidos do titular relativos à notificação da finalidade de utilização, divulgação, correção, aditamento ou eliminação de conteúdos, cessação da utilização, eliminação e cessação da divulgação a terceiros dos seus dados pessoais (doravante "Pedidos de Divulgação").
